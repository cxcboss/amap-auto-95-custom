# 1.3.9.5 正式版清理与发布

版本为 1.3.9.5 / 26000012，继承 1.0—1.2 已交付的原生扩展设置、更新兼容、播报控制和页面过渡调整。本次用户明确授权清理测试残留、打包发布正式更新并覆盖安装到指定车机，不进行 App 运行或实车功能测试。

## App 内清理

- 对实际交付的 1.2 APK 和当前源码核对后，未发现 QA 限核助手、探针类、本地更新测试接口或 instrumentation。
- 移除 AndroidManifest 中的 `com.autonavi.amapauto.receiver_test` 测试广播别名。它原本复用 `AmapAutoBroadcastReceiver` 的标准协议分支；保留该 receiver、其他广播注册及 `AUTONAVI_STANDARD_BROADCAST_RECV`，不删除车机通信能力。厂商主 dex 内未注册的旧别名分支不做破坏性重写。
- 自定义 Java 编译使用 `-g:none`，辅助 dex 使用 `d8 --release`；仅对自有 `libamapextras.so` 执行 `llvm-strip --strip-unneeded --remove-section=.comment`。JNI 导出和原生 `.text` 与 1.2 一致，不对厂商引擎批量剥离符号。
- 正常的导航语音试听、原生扩展设置、开机启动、地图及导航功能保留；不把产品功能当成测试代码删除。
- 继续使用旧包证书及包名，以保留覆盖升级关系和用户配置。签名文件是构建依赖，不能随测试产物删除；编译用 stubs 不打入辅助 dex。

`release.py inspect` 在发布 APK 的边界检查版本、签名和对齐，并拒绝 debuggable、testOnly、instrumentation、测试广播注册及已知 QA 更新地址、限核属性、探针标记。此检查不会把厂商 SDK 中含有 test/debug 单词的正常代码盲目删掉。

## 本地环境清理

首轮按固定清单移出 293 项、约 3156.8 MiB：旧构建目录、QA 更新测试包及独立源码副本、性能脚本工作目录、重复 dex/so、临时安装包、截图、采样、反汇编输出与构建日志。文件移入本机废纸篓并保存恢复清单，尚未物理释放磁盘空间。

保留当前维护源码、构建基包、项目根目录正式历史 APK、原始包、签名、Markdown 报告、符号表和用户数据。此前报告中的原始测试截图、trace 与临时库路径属于历史证据；清理后不再保证那些临时路径存在，必要时从恢复清单取回或从基包重新提取。

本机旧更新测试服务未运行，指定车机未发现本项目的 ADB reverse 或限核属性。车机上其他项目的探针、trace 及现有应用不在清理范围内。此前测试手机当前未连接，未进行额外手机端清理。

新版本构建产生的中间文件在发布与安装核对完成后再移入废纸篓；保留最终签名 APK、发布资产和校验记录。

## 发布和安装

执行 `release.py prepare` 生成签名 APK、update.json、SHA256SUMS.txt 与更新说明。确认源码提交已推送 main 后执行 `release.py publish`：先上传草稿、核对资产摘要与名称，再公开为 Latest，最后核对公开元数据及下载地址。仓库简介继续保持为空。

正式版本地址：<https://github.com/cxcboss/amap-auto-95-custom/releases/tag/v1.3.9.5>。发布成功须以脚本和 GitHub 返回结果为准；本地 prepare 不能代替公开发布。

覆盖安装使用明确设备目标的 `adb install -r`，不卸载、不清数据。安装后只读取已安装 versionName、versionCode 和 base.apk 的 SHA-256，与交付文件核对；不主动启动 App 或进行地图、导航、车辆操作。
